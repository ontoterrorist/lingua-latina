# Escenas pixel art

Diez fondos originales en PNG, de 600 × 72 píxeles, ilustran los espacios y temas de los diálogos. Se asignan a los 35 niveles del juego.

Cada escena tiene dos archivos:

- `.png`: imagen usada por el juego.
- `.pxo`: proyecto editable guardado desde Pixelorama 1.2.3.

Las escenas usan formas geométricas propias y una paleta limitada; no se copiaron sprites ni ilustraciones de los recursos enlazados. La skill personal `pixel-art-scenes` guarda referencias y pautas para crear arte de juego original en Pixelorama, inspiradas por [awesome-pixel-art](https://github.com/Siilwyn/awesome-pixel-art).
